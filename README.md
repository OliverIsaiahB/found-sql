# Databases & SQL Fundamentals

A from-scratch beginner project that teaches the relational model and the SQL every data, backend, and analytics job depends on. Working against a real SQLite schema for a small bookstore, you start with what a table even is, then build up SELECT and WHERE, ORDER BY and LIMIT, aggregate functions and GROUP BY, the difference between WHERE and HAVING, joins across multiple tables, subqueries, and finally basic schema design with primary and foreign keys. Every concept is a runnable SQL query against a seeded database, so you learn by asking real questions and getting real answers.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).

## Stack
- SQL
- SQLite
- Relational Model
- Schema Design
